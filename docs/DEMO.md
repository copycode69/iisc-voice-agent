# Demo script (2–3 minutes)

1. Open Vaani. Point at the "STT / TTS on device" badge, then open Models and show the names and sizes.
2. Turn airplane mode on. Speak an English sentence. The transcript appears. Tap Say test lines and let a Hinglish line play.
3. Turn airplane mode off. Say, in order:
   - What is the weather forecast for Bangalore tomorrow?
   - Can you set a reminder for my meeting at 5 PM?
   - Mujhe kal subah 7 baje ka alarm set karna hai.
   - Aaj ka schedule kya hai, aur meri next meeting kab hai?
   After each reply, point at the latency line under the bubble.
4. Open Clock and show the 7 AM alarm. Open Calendar and show the 5 PM reminder.
5. Open Metrics, then Benchmark. End on this README on GitHub.
